# AETHER · Premium Product Showcase

一个纯静态、零依赖的高端产品展示网页，充分展现产品设计的高大上实力与前端炫技能力。

**仓库地址**：https://github.com/doraemonRain/premium-showcase  
**在线预览**：开启 GitHub Pages 后访问  
`https://doraemonRain.github.io/premium-showcase/`

## 炫技亮点

- **自定义光标** + 悬停放大
- **多层动态光球** 与环境渐变氛围
- **玻璃拟态卡片** + 实时 3D 倾斜交互
- **鼠标跟随径向光效**（Feature 卡片）
- **滚动驱动入场动画**（Intersection Observer）
- **数字滚动计数器**
- **统一弹性缓动曲线** `cubic-bezier(0.16, 1, 0.3, 1)`
- **旋转光环装饰**
- **纯 CSS 渐变文字流动**
- **60fps 性能友好**（仅 transform / opacity）

## 技术栈

- 纯 HTML / CSS / 原生 JavaScript
- 无任何框架或库
- 现代 CSS（自定义属性、backdrop-filter、渐变、3D transform）

## 本地预览

直接打开 `index.html`，或：

```bash
npx serve .
```
